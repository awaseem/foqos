# PIN System Shortcuts

An optional PIN-based system for ending an active Foqos session using Apple Shortcuts.

The system is designed for situations where another person, such as a partner, accountability partner, or parent, controls the PIN required to unlock Foqos.

## How It Works

Each PIN system consists of a matching pair of Apple Shortcuts:

- **Foqos PIN (COLOR)** generates the PIN.
- **Foqos Unlock (COLOR)** requests the PIN and, when the correct PIN is entered, ends the active Foqos session.

The PIN changes approximately every 10 minutes and is generated using UTC, so both devices can independently calculate the same PIN regardless of their local time zone.

Each color is a separate PIN system. A PIN generated by one color only works with the matching "Foqos Unlock" shortcut of that color.

## Available Pairs

| PIN Generator | Unlock Entry |
| --- | --- |
| Foqos PIN (RED) | Foqos Unlock (RED) |
| Foqos PIN (BLUE) | Foqos Unlock (BLUE) |
| Foqos PIN (GREEN) | Foqos Unlock (GREEN) |
| Foqos PIN (YELLOW) | Foqos Unlock (YELLOW) |

## Setup

For a basic two-person setup:

1. Choose one color.
2. Install **Foqos Unlock (COLOR)** on the device using Foqos.
3. Install the matching **Foqos PIN (COLOR)** on the other person's device.
4. When the Foqos user needs to end an active session, they run their "Foqos Unlock" shortcut.
5. The other person runs the matching Foqos PIN shortcut and provides the generated PIN.
6. Enter the PIN into Foqos Unlock to end the active session.
7. Additionally, for easy use, you can edit the shortcuts to "Add to Home Screen" so that it may appear as an iPhone application.

## Using Multiple Pairs

The different colors allow multiple independent PIN systems to be used without sharing the same PIN sequence.

For example, two partners who want to hold each other accountable can use two different colors:

- Person A keeps Person B's PIN generator color.
- Person B keeps Person A's PIN generator color.
- Each person keeps only their own corresponding "Foqos Unlock" shortcut color.

This prevents one person's PIN generator from being used with the other color's unlock entry shortcut.

## Notes

- Matching colors must always be used together.
- The PIN is time-based and changes approximately every 10 minutes.
- The approximately 10-minute interval is built into the Shortcut's time-based PIN generation logic and is not intended to be user-configurable.
- PIN generation uses UTC, so the devices do not need to be in the same time zone.
- Neither shortcut will work if you have both the PIN generator and the PIN entry shortcut on the same device at the same time.
- **Do not rename any of the PIN System Shortcuts.** The system relies on their expected names (to prevent bypass), and changing them will cause an error. To fix this error, revert the shortcut's name.
- These Shortcuts are intended as an optional accountability tool for Foqos.
