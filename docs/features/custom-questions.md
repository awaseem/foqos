# Custom question challenge

Optional module atop the intentional-access foundation; no steps, location, motion
or partner dependency. Choose Questions in a profile's challenge settings. Add
1–10 questions and the accepted answer to each. Before temporary access, confirm
your intention and answer every question. Matching ignores case and edge whitespace;
blank, incorrect and oversized responses fail. Existing confirmation configurations
continue to decode without question data. IDs must be unique, text is bounded.

Answers stay in local profile/app-group storage, in plain text like other settings.
Do not put passwords or secrets here. This is voluntary reflection, not a secure
exam. Stop still ends the session without answering; no permanent lockout.
Tests cover matching, bad inputs, question limits, duplicate IDs and persistence.
