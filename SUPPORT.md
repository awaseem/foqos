# Getting help with Foqos

Start with the searchable [Help Center](https://www.foqos.app/support.html). It covers setup,
blocking strategies, troubleshooting, and known limitations. Then search
[open and closed issues](https://github.com/awaseem/foqos/issues?q=is%3Aissue) for previous answers.

Foqos is maintained in spare time. Individual setup support is not available, and a response or fix
is not guaranteed. Support questions and duplicates may be closed with a link to the relevant answer.

## Why support is changing

*A note from Ali · October 13, 2026*

I never expected Foqos to grow to 100,000+ users. It's by far the most successful project I've
created, and I'm grateful that so many of you find it useful.

Unfortunately, the volume of support has become impossible for me to keep up with. I'm getting
hundreds of messages a day, and I feel awful that I can't reply to all of you.

I use GitHub Issues to track development work and important bugs, but most issues now turn into
troubleshooting individual setups, which takes a huge amount of time. Some of those conversations
help me improve the app's UX, and I understand how frustrating it is when something doesn't work.
But there is always another problem to investigate, and I can't keep providing that level of
personal support.

Starting October 13, 2026, I'm asking everyone to search the Help Center and existing issues before
opening a report. I've gone through past issues to put these answers together, and I'll continue
updating them so you have somewhere to find help. GitHub will remain open for actionable bug reports
and new feature proposals.

I want to spend more time with my family and keep building an app I love. Making support sustainable
is part of making that possible. I hope you can understand, and thank you for being part of Foqos.

— Ali

## Reporting a bug

Use the [bug-report form](https://github.com/awaseem/foqos/issues/new?template=01-bug-report.yml)
if you can describe a problem that is not already covered. Include:

- The support answer you tried and what happened, or what you searched for if nothing matched.
- Device models, exact OS versions, and Foqos versions; include both devices for Mac sync problems.
- Steps to reproduce, relevant profile settings, and how often it happens.
- Expected behavior and actual behavior, with a recording or screenshot when useful.
- Relevant diagnostics if available. GitHub is public: remove private details before sharing.

Intermittent problems are welcome when you can describe the circumstances; you do not need to know
the root cause. A closed report does not necessarily mean a problem was fixed. Check its explanation
and linked reports before filing the same issue again.

Foqos supports iPhone and its Mac companion. Running the iPhone app on an iPad does not imply native
iPad support. Follow [#287](https://github.com/awaseem/foqos/issues/287) for that request.

## Suggesting a feature

Check the available strategies and previous decisions first. Use the
[feature-request form](https://github.com/awaseem/foqos/issues/new?template=02-feature-request.yml)
to explain the unmet need and why existing options do not cover it. A request does not create a
commitment to implement it. See [CONTRIBUTING.md](CONTRIBUTING.md) before preparing a contribution.
